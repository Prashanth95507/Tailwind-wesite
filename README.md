this repository contains the images needed for the gallery section

This project is a simple, responsive image gallery website built using HTML and Tailwind CSS. It features a clean layout with navigation, a grid-based image gallery, and a footer with the home page with .

The purpose of this project is to demonstrate basic front-end web development skills, including layout design, responsive grids, and utility-first styling with Tailwind CSS.

now the styling on these two webpages are made with the help of tailwind css


the content of tailwind css applied to the webpages are the following:


-grid : used to establish a grid which allows me to arrange the images in a neat way
-grid-cols : helps to specify how many columns should be present on the page
-mx : this is for the horizontal margin application
-text : used to specify properties of text
-bg : used to specify properties of the background of an element
-flex : specifies the box around an element
-justify : used to tell the page where to put certain elements or sections

for more information go to the tailwind css website a great website for all your tailwind css definitions if mine were too vague and learn more tailwind css from looking in there catalog


HTML5 – structure of the webpage
Tailwind CSS (via CDN) – styling and layout
Responsive Design Principles – ensures usability across devices via use of tailwind css properties (sm, md, xl, lg)


Created as a beginner-friendly web development project to practice Tailwind CSS and responsive design.
